# Root-generation prerequisite RC5 full-wire successor

RC4 corrected the review-schema key aliases but exposed a second profile-shape failure: EVALUATOR-CONFIG.json embedded detailed mode objects instead of the frozen two-string modes list and omitted required evaluator config flags.

RC5 is the final prompt-binding successor in this sequence.

It preserves the qualified RC3 runtime, transport, profile surface, checker, launcher, information aperture and attempt budgets. It changes only PROFILE-WRITER-TASK.md to bind the complete machine-readable profile surface:

- exact PRIMARY-CONFIG.json;
- exact EVALUATOR-CONFIG.json;
- exact REVIEW-SCHEMA.json key families;
- minimal required prompt tokens.

If the frozen checker still reports PROFILE_CONFIGURATION after this full literal binding, bootstrap profile authoring with this model/runtime/task configuration is treated as falsified and the prompt-repair loop stops.

If the checker passes, the prerequisite reaches SUPPORTED_FOR_GENERATION_EXECUTION.

Generation capability remains UNKNOWN either way until a separate generation experiment actually runs.
