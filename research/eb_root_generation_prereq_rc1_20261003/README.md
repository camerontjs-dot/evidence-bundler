# Public root-generation prerequisite qualification RC1

This is a separate public research successor to Evidence Bundler PR #125.

RC0 ended BLOCKED before semantic calibration. This successor does not repair, reroll, or reinterpret RC0. It tests only whether the two prerequisites that blocked RC0 can be established before any case, control, oracle, weak-system, or target-generation exposure:

1. a complete frozen primary/evaluator profile surface, including explicit uncertainty handling and a fully defined decisive review wire; and
2. a bounded externally generated custody receipt that can be checked mechanically without relying on a model to emit a long self-attestation.

Generation capability remains UNKNOWN unless a later separately authorized execution actually exercises generation.

## Boundary

Allowed here:
- public bootstrap/profile specification;
- one fresh bootstrap-only profile-writing attempt;
- one external custody-verification attempt;
- mechanical validation and preservation of failures.

Not allowed here:
- semantic evaluator calibration;
- any of the twelve RC0 generation cases;
- weak generators;
- decisive review;
- tally/scoring;
- PR #124 private roots, population construction, corpus access, retrieval, or passage review;
- production source/config/version changes;
- merge, release, or promotion.

Execution is CONTEXT-FREE REQUIRED. Use only the frozen launch packet and actual runtime facts. Do not supply this PR narrative to the fresh profile writer.

A passing RC1 authorizes only a later generation execution against a separately frozen scientific packet. It does not establish generation capability.
