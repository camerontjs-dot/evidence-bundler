# Root-generation prerequisite qualification RC1

## Objective / decision

Determine whether a fresh bootstrap-only profile writer and an externally observed custody route can establish, before semantic exposure:

1. complete frozen primary and semantic-evaluator profile artifacts; and
2. a complete machine-checkable custody receipt tied to the actual request, response, allowed sources, runtime facts, and extracted profile bytes.

If both pass, the bounded result is SUPPORTED_FOR_GENERATION_EXECUTION. This means only that the prerequisite apparatus is ready for a separately authorized generation experiment. It is not generation evidence.

## Competing explanations

H1: RC0 failed because its returned writer artifacts were incomplete, not because the requested profile surface is impossible to express.
H2: the required evaluator uncertainty/review surface can be made explicit in a frozen public contract without answer-bearing examples.
H3: RC0 custody failed because the custody envelope asked for an unnecessarily large generated report; an external bounded receipt can verify the route without semantic self-attestation.
H4: the runtime/launcher cannot actually establish the required request/source/custody facts even with a bounded receipt.

This RC1 distinguishes these prerequisite explanations only. It does not distinguish generator capability.

## Experiment controls

CONTEXT-FREE REQUIRED.

Fresh writer pre-freeze allowlist:
- BOOTSTRAP-MANIFEST.json
- PROFILE-WRITER-TASK.md
- AUTHORING-RUBRIC.json
- PROFILE-SURFACE.json
- actual destination/runtime capability facts supplied without cases or prior outputs

Pre-freeze denylist includes every case/control/oracle source, RC0 returned profiles/native outputs, PR/issue narrative, project/conversation memory, private material, and target/evaluator results.

The writer gets one attempt and returns exactly the five required profile artifacts. It does not execute them.

The custodian is external to the writer model. It captures the actual native request/response, runtime metadata actually observable, exact opened-source identities, response completion state, and hashes of the five extracted profile artifacts. The model is not asked to generate the custody receipt.

The custody receipt must remain bounded. It may record token counts and done reason, but it must not contain generated prompts, source bodies, semantic answers, or whole native responses. Native request/response bytes are preserved separately and referenced by digest.

## Acceptance

All of the following are required:

- writer request contains only the allowlisted public inputs plus runtime facts;
- no denylisted source was opened or supplied before profile freeze;
- exactly five required returned profile artifacts are extracted without repair;
- primary profile is explicitly root-only and proposal-null;
- evaluator profile defines separate calibration and decisive modes under one semantic instruction surface;
- decisive review wire contains row_alias, root_status, decision, and the five named Boolean checks;
- root_status and decision both explicitly admit uncertain;
- evaluator may not edit proposals;
- exact prompt/config/schema bytes are frozen before any semantic case/control exposure;
- external custody receipt is complete, schema-valid, tied to actual native request/response digests and observed runtime facts;
- custody checker passes without consulting case/control/oracle material;
- protected production bytes are unchanged.

## Failure / stop states

BLOCKED_PROFILE_CONFIGURATION:
the one fresh writer attempt does not return a complete required profile surface.

BLOCKED_CUSTODY_VERIFICATION:
the external custody route or receipt cannot be completed and checked within the one allowed custody attempt.

BLOCKED_AUTHORITY:
required pinned authority/runtime facts cannot be established.

CONTAMINATED:
forbidden material is exposed before profile freeze.

INCONCLUSIVE:
the apparatus executes but the checks cannot distinguish a valid prerequisite setup from an invalid one.

SUPPORTED_FOR_GENERATION_EXECUTION:
all acceptance conditions above are observed.

Stop immediately on any terminal state. Do not consume semantic calibration, generation, weak-system, decisive-review, or tally attempts in this RC1.
